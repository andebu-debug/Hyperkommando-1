# Hyperkommando 1: Operation Stålfågel

![Hyperkommando 1](logo.png)

Et heftig skytespill i Doom / Unreal / Duke Nukem / Commando-stil – rett i nettleseren, på mobil og PC.

- 20 baner i 4 verdener · 4 bosser · 9 våpen
- Lag din egen helt – ansiktet reagerer når du blir truffet
- Schæferen REX hjelper deg på de tøffeste banene
- Kan installeres som app på mobil og PC

**Wåle production 2026**
